# Шынбаға — честная цена кредита

«Шын баға» по-казахски — «настоящая цена». Рабочий слоган: «Кредит на человеческом языке».

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Ffandex01337-hash%2Fshynbaga&project-name=shynbaga&env=GEMINI_API_KEY&envDescription=%D0%91%D0%B5%D1%81%D0%BF%D0%BB%D0%B0%D1%82%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BB%D1%8E%D1%87%20Gemini%3A%20aistudio.google.com%2Fapikey&envLink=https%3A%2F%2Faistudio.google.com%2Fapikey)

**Открыть своё приложение за пару минут:** нажмите кнопку выше (Vercel сам склонирует репозиторий и спросит ключ `GEMINI_API_KEY`), либо запустите локально по инструкции ниже. Без ключа работают ручной ввод и все демо-пресеты (`DEMO_FALLBACK=true`).

MVP для хакатона: вставьте текст договора/рекламы, сфотографируйте предложение или введите условия — приложение покажет реальную цену кредита, переведёт её в понятные вещи и найдёт ловушки. Русский и казахский, тенге (₸).

## Принцип

```
текст / фото / PDF ──LLM──▶ параметры + дословные цитаты
                              │
               пользователь проверяет и правит форму
                              │
        детерминированный движок lib/finance (целые тиыны, тесты)
                              │
     UI показывает цифры по шаблонам; LLM пишет только вывод БЕЗ цифр
```

LLM не считает деньги. Если LLM недоступен, ручной ввод работает полностью.

## Установка и запуск

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env.local   # Windows: copy .env.example .env.local
npm run dev                  # http://localhost:3000
npm test                     # движок, флаги, редактирование ПД, схемы, i18n
npm run typecheck
npm run build
```

Без ключей приложение запускается: ручной ввод работает, а пресеты берут результат из `fixtures/*.json` при `DEMO_FALLBACK=true`.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `LLM_PROVIDER` | `gemini`, `anthropic` или `openai`. Не задан — берётся первый, для которого есть ключ |
| `LLM_MODEL` | модель; по умолчанию `gemini-3.5-flash-lite` / `claude-sonnet-5-5` / `gpt-4o-mini`. Для фото нужна модель с vision |
| `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` | ключи, только на сервере. Бесплатный ключ Gemini: https://aistudio.google.com/apikey |

**Gemini как бесплатная основа.** Подходит для разработки и демо на вымышленных документах. На бесплатном тарифе Google использует содержимое запросов для улучшения своих продуктов (по его странице тарифов, на платном — нет), а маскирование ПД работает только для текста, не для фото. Для реальных договоров людей переходите на платный тариф или другого провайдера. Лимиты запросов бесплатного тарифа смотрите в AI Studio: на странице тарифов они не указаны.
| `DEMO_FALLBACK` | `true` — при недоступном LLM пресеты отдают сохранённый разбор |
| `RATE_LIMIT_PER_MIN` | лимит запросов к API с IP, по умолчанию 10 |

## Деплой на Vercel

1. Залить репозиторий в GitHub, в Vercel — **Add New → Project**, выбрать репозиторий (Framework: Next.js определится сам).
2. В **Settings → Environment Variables** добавить переменные из таблицы выше.
3. Deploy. Функции API имеют `maxDuration = 60`.
4. Rate limit и кэш живут в памяти инстанса. Для продакшена реализовать `RateLimiter` из `lib/rateLimit.ts` поверх Redis.

## Сценарий демо на 60 секунд

1. **0–10 с.** «Мне пришла реклама микрозайма». Открыть приложение на телефоне, нажать **Сфотографировать** и снять рекламу «0,3% в день, одобрение за 5 минут» (подсказка про закрытие личных данных видна на экране). Запасной вариант: кнопка-пресет **Микрозайм «0,3% в день»**.
2. **10–20 с.** Шаги «Читаю договор… Ищу скрытые платежи… Считаю реальную цену…». Откроется форма с цитатами из документа. Поля, которых нет в рекламе (годовая ставка, ГЭСВ), подсвечены «Не указано в документе». Ввести месячный доход (например 250 000) и нажать **Посчитать реальную цену**.
3. **20–40 с.** **Ценник правды**: «Берёте 100 000 → Отдадите … → Переплата …». Прокомментировать карточки: «0,3% в день = 109,5% годовых», «переплата — N ваших зарплат», «каждый день кредита стоит D ₸».
4. **40–55 с.** **Красные флаги** с цитатами: ставка в день, давление срочностью, ловушка продления. Двинуть ползунок досрочного погашения и ползунок просрочки.
5. **55–60 с.** **Что спросить у банка** → **Отправить родным**. Если время есть, нажать пресет «SMS „кредит одобрен“»: большое красное предупреждение о мошенничестве.

Контрольный случай: пресет «Честное предложение» — без красных флагов.

**Кнопка «Сгенерировать пример договора»** (`/api/sample`): нейросеть пишет новый вымышленный договор прямо на сайте, он показывается как документ, дальше «Разобрать и посчитать». Каждый раз условия другие: сервер выбирает случайные сумму, срок, ставку и минимум две платные добавки (комиссия за выдачу, ежемесячная комиссия, страховка в теле кредита), плюс заниженную ГЭСВ, и требует от ИИ вписать их дословно. Ответ проверяется: числа на месте, нет названий реальных банков, ИИН и телефон принудительно вымышленные. Таймаут 15 с; при любом сбое или без ключа показывается готовый договор из `fixtures/contract.json` (на руки 2 352 000 ₸, отдадите около 3 306 744 ₸, +41%, эффективная ставка около 26,4% при заявленной 21,0%), и он же разбирается без LLM при `DEMO_FALLBACK=true`.

## Решения и допущения

- **Деньги** — целые тиыны; `Intl` используется только для показа. Последний платёж закрывает остаток, поэтому итог может отличаться от «идеального» на доли тиына (в золотом тесте допуск 0,10 ₸).
- **«Берёте на руки»** = сумма минус комиссии/страховка, удержанные при выдаче. Переплата = «Отдадите» − «на руки».
- **Эффективная ставка** — наша IRR-оценка по месячным потокам, не официальная ГЭСВ. Для рассрочки считается от цены сразу.
- **Ставка в день** переводится простым умножением ×365; для расчёта графика она применяется как годовая номинальная с месячной капитализацией, срок берётся в месяцах из формы.
- **Страховка «разово»** по умолчанию считается удержанной из суммы (можно сменить в форме на «сверху» или «добавляется к кредиту»). **Проценты комиссий** считаются от суммы кредита.
- **Пени за просрочку** считаются как % в день от просроченного платежа; в договоре база может быть иной — это сказано в интерфейсе.
- **Пороги** (30% / 50% дохода, 5 п.п. разницы ставок и т.д.) — эвристики из `lib/config/thresholds.ts`, не законодательные нормы. Законодательные лимиты не используются.
- **Цитаты проверяются**: сервер сверяет цитаты LLM с исходным текстом и помечает те, что в нём не найдены. Для фото проверка невозможна.
- **Фото**: уменьшается до 1600 px и перекодируется в JPEG в браузере (убирает EXIF). Скрыть личные данные на фото нельзя — об этом предупреждение на экране.
- **Скан-PDF** без текстового слоя не читается (OCR нет): предлагаем сфотографировать страницы.
- **Если схема не сошлась** — 1 повтор с описанием ошибки, затем понятное сообщение и ручной ввод.

## Перед демо проверить

- `lib/config/resources.ts`: ссылки и телефоны раздела «Если уже не справляюсь» сверить с официальными источниками и проставить `verifiedAt`. Пока не проставлено, UI показывает «проверьте актуальность».
- Казахский перевод (`lib/i18n/kk.ts`) подготовлен без носителя языка — показать носителю.
- Прогнать пять пресетов вживую с реальным ключом: их разбор в `fixtures/` написан вручную как эталон, а не снят с модели.
